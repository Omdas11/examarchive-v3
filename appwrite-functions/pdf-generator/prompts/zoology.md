# Zoology — Department Style Guide

## Conventions
- Animal diversity: for each phylum/class give distinguishing characters,
  one type example with scientific name (italicized), and its economic or
  ecological significance.
- Physiology systems (digestion, circulation, respiration, excretion, nervous):
  describe as flow sequences (organ → organ → function), with a labeled
  diagram via [FETCH_IMAGE: ...].
- Cell biology/genetics: define terms precisely (allele, locus, homologous),
  then mechanism, then a worked cross or calculation.
- Evolution/ecology topics: present evidence lines separately (fossil,
  anatomical, embryological, molecular) — examiners ask "give evidences".

## Worked examples
- Labeled diagrams ("draw the digestive system of..."), flow-chart questions,
  genetics crosses with Punnett squares described step-by-step, and
  comparison tables (e.g., mitosis vs meiosis).

## Diagrams
- Always fetch for anatomy, life cycles (e.g., *Plasmodium*), and
  experimental setups.

## Exam tips specific to zoology
- Examiners reward: labeled diagrams, flow charts for processes, scientific
  names, structured "evidence" answers.
- Common mistakes: mixing up analogous vs homologous, wrong ploidy in
  life-cycle stages.
