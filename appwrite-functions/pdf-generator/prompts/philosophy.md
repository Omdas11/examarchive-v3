# Philosophy — Department Style Guide

## Conventions
- Every argument reconstructed formally: numbered premises → conclusion.
  Then: is it valid? Is it sound? Say explicitly.
- For each theory/position: the claim → the argument for it → the strongest
  objection → the reply (or why the objection stands). This
  objection-reply structure is what examiners look for.
- Key distinctions: define each term, then contrast (e.g., analytic vs
  synthetic, deontology vs consequentialism) in a compact table.
- Name the philosopher with each view (Kant, Hume, etc.) and one line on
  their broader project for context.

## Worked examples
- Model answers: one short note (define + explain + example) and one essay
  (thesis → exposition → objection → reply → evaluation) per topic.

## Exam tips specific to philosophy
- Examiners reward: argument reconstruction, charitably stated objections,
  precise terminology, original evaluation in the conclusion.
- Common mistakes: strawmanning opponents, asserting without arguing,
  confusing validity with truth.
