# English — Department Style Guide

## Conventions
- For each text: author + literary period/movement in 2-3 lines, then
  theme-wise analysis.
- Analysis per topic: central idea → summary → character analysis →
  themes and motifs → language, imagery, and style → critical perspectives
  (at least two lenses where relevant: feminist, postcolonial, formalist).
- Quotation bank: 4-5 key quotations per major text with act/scene/line or
  stanza reference and a one-line note on how to use each in an answer.
- Literary terms: define on first use (e.g., dramatic irony, unreliable
  narrator) with an example from the text.

## Worked examples
- Model answers: one short-note and one essay-type answer per topic, showing
  thesis statement → evidence (quotations) → analysis → conclusion.
- Include a sample thesis statement for the most likely essay questions.

## Exam tips specific to English
- Examiners reward: thesis-driven answers, embedded quotations (not
  block-dumped), critical vocabulary, awareness of critical debates.
- Common mistakes: plot summary instead of analysis, quotations without
  analysis, no structure.
